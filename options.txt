path,                           label,                    type,           owner

/company/tech,                  Technology,              division,      Ravi Chandra

There is no id column and no parent column. The hierarchy is encoded entirely in a string — a node's parent is its own path minus the last segment.

OPTION 3 : Client: a BI or pivot-table export. Each row is a complete branch, not a node.


Level 1,        Level 2,            Level 3,          Headcount,    Budget
Amara Osei,     Ravi Chandra,       Priya Nair,       12,           850000
Amara Osei,     Ravi Chandra,       Diego Marquez,    8,            620000
Amara Osei,     Lena Fischer,       Ollie Brennan,    4,            310000
Amara Osei,     Lena Fischer,       Tom Whitfield,    3,            240000
Amara Osei,     Marcus Webb           , ,             2,            150000


there are no ids, no parent references, and — the big one — the row count doesn't match the node count. Five rows describe eight nodes. Amara appears four times, 
Ravi twice, Lena twice. Every non-leaf node has to be invented by de-duplication; they exist only implicitly. The last row is ragged (no Level 3), so Marcus is 
a leaf one rung up.
